 # ESP32 OLED LDR Display

This project uses ESP32, an LDR sensor and an SSD1306 OLED display.

## Components

- ESP32
- LDR Sensor
- SSD1306 OLED Display

## Working

The LDR reads the light level.
The light value is displayed on the OLED and Serial Monitor.
